# docs/viec — yêu cầu gửi bộ phận khác (văn phòng OZ)

Claude dự án / dev **không nhờ CEO chuyển thư**. Cần bộ phận khác làm gì (thường là **quản trị server**), tạo 1 file ở đây rồi commit:

`yeu-cau-YYYY-MM-DD-<slug>.md`
```
# Yêu cầu: <việc> — gửi: quản trị server — từ: DA-HS (hs-code-api)
Mục đích: …
Điều kiện trước: …
Cần làm: 1. … 2. … 3. …
Khi nào: …
Kiểm tra xong (checklist): - [ ] …
Đường lùi (rollback): …
```
Văn phòng OZ quét thư mục này → ghi vào bảng việc chung (Gitea `ozvietnam/oz-infra-codex`, `oz-viec`) → người nhận làm → đánh dấu checklist tại chính file này. Không ghi khoá/mật khẩu vào file.
